# ULTRON

Electron desktop shell for **Tony** — your personal AI assistant.

## Run

```powershell
# Terminal stack only
npm run live

# Desktop app (starts stack if needed)
npm run ultron
```

HUD: http://localhost:8787/

## What it is

- **ULTRON** = personal assistant OS shell (Electron)
- **Tony core** = ReAct brain, skills, Obsidian brain, Voicebox, desktop bridge
- Self-evolves on idle (skill XP + vault notes)
- Vibe coding + full laptop control playbooks
