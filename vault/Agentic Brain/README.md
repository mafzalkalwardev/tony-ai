# Agentic Brain

Obsidian-compatible markdown vault for Tony.

- `Daily/` — daily consolidation notes
- `Skills/` — learned / practiced skill notes
- `Inbox/` — notes Tony writes via `brain_write`
- `GRAPH.md` — auto-generated graph index

Open this folder in Obsidian to browse links/tags. Tony rebuilds `data/brain_graph.json` on daemon ticks.
